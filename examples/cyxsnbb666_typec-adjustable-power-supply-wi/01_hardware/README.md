# 硬件设计

## 核心特性
- 输入：Type-C PD 诱骗（CH224K，默认诱骗 20V；换 CH224A 可支持 28V PD3.1）、DC 2.5mm 输入（≤35V）；输入范围 5V–32V，建议 ≥12V
- 输出：4mm 香蕉头 + USB-A 母口；输出 2.5V–36V 连续可调，0–10A 连续可调，最大带载 200W
- 主控 MCU：STM32F103CBT6（Cortex-M3，72MHz，128K Flash）
- 电源控制芯片：SC8701QEDR（Buck-Boost 控制器，2.7–36V 输入，2–36V 输出，PWM/DAC 调压）
- 电流/电压检测：2× INA226AIDGSR（I²C，输入/输出总线电压电流功率）
- PD 诱骗芯片：CH224K / CH224A
- 显示屏：2.4 寸 TFT 彩屏 ILI9341（320×240，18P 插接款）
- 交互：1 颗拨轮开关；CH340N 串口转 USB；SWD；蓝牙模块
- PCB：76×54mm，4 层板，1.6mm，阻容 95% 为 0603
- 散热：12V 5×5cm 风扇，温控调速；30×10×20mm 锂电池槽
- 保护：双输入理想二极管防反接（MX16171D+NMOS）、输出防倒灌、短路/掉压/欠压保护、软件限流、IWDG 看门狗
- 存储：W25Q256 FLASH 存配置
