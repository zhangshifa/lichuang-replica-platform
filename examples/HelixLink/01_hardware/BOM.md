# BOM 物料清单

> 说明：完整 BOM（精确型号 / 位号 / 封装 / 供应商料号）见立创开源项目页的 BOM 附件，
> 可在立创 EDA 一键导出。下表为**按功能分类的选型清单与要点**，用于复刻前评估与采购规划。
> 具体器件以立创工程导出为准。

## 分类清单

| 类别 | 典型器件 | 作用 | 选型要点 |
| --- | --- | --- | --- |
| 主控 MCU | 带 USB 的 ARM Cortex-M | 运行固件、USB 通信 | 需原生 USB 外设；具体型号见立创工程 |
| USB 接口 | USB Type-C / Micro-B + ESD 保护 | 与上位机连接 | 注意 CC 电阻与走线阻抗 |
| 电平转换 | 电平转换 / 缓冲器 | 适配不同 IO 电压 | 关注方向控制与速率 |
| 隔离 | 数字隔离器 / 光耦 | 信号隔离保护 | 调试通道两侧隔离 |
| 电源 | LDO / DC-DC | 板上供电 | 输入输出压差与电流余量 |
| 调试接口 | 排针 / 连接器 | SWD/JTAG/UART | 间距与防呆 |
| 无源器件 | 电阻 / 电容 / 电感 | 去耦、滤波、偏置 | 封装与精度按 BOM |
| 结构件 | 外壳 / 按键 / 指示灯 | 装配与交互 | 与 PCB 尺寸匹配 |

## 采购建议

- 立创商城「BOM 表一键配单」可自动匹配型号，降低选错风险。
- 极性 / 易损器件（LED、电解电容、MCU）建议多备 10%~20%。
- 封装（footprint）必须与立创工程严格一致，否则无法焊接。
