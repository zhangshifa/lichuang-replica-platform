# 材料清单与采购

复刻 HelixLink 所需材料分三类：

1. **PCB 与 SMT**：在嘉立创下单（立创开源一键下单，含 PCB 打样与 SMT 贴片可选）。
2. **分立器件**：按 BOM（`01_hardware/BOM.md`）在立创商城 / 得捷 / 贸泽采购。
3. **结构件与辅料**：外壳、排针、线缆、焊锡、隔离柱等。

## 采购注意事项

- 优先使用立创商城「BOM 表一键配单」，避免型号选错。
- 注意器件封装（footprint）与 BOM 严格一致。
- 备品：易损/极性器件（LED、电解电容、IC）建议多备 10%~20%。
- 若自行 SMT，确认钢网与元件封装匹配；手工焊接优先选较大封装（0805 及以上）。
